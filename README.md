# ModKit_USD_Maya_to_Unreal_exporter
### Onedirectional USD Pipeline exporter for enviroment artists exporting modular kits.
This tool, will grab your maya modular kits selection and automatically export as a single USD file and reimport the meshes as individual SM in Unreal. The goal was to implement asset transfer between Maya and Unreal, and starting to dive into USD as a topic.
